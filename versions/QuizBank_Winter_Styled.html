ملاحظات مهمة

  • الاختبارات المستوردة تبقى فقط على نفس المتصفح ونفس الجهاز.
  • المحاولة تعتمد على تنسيق الملف، فإذا كان الملف غريب التنسيق قد يُقسَّم سؤال بشكل خاطئ. لهذا توجد شاشة المراجعة.
  • يمكنك حذف أي اختبار، حتى الاختبار الأصلي، بزر Delete this set أو حذف كل شيء بزر Clean all test sets. ولاسترجاع الاختبار الأصلي اضغط Restore original.
  • لأفضل نتيجة في الاستخراج: اطلب من أي ذكاء اصطناعي (ChatGPT / Claude / Gemini...) تحويل أسئلتك إلى التنسيق الصحيح بهذا الـ Prompt، ثم احفظ الناتج كملف .txt أو .docx وارفعه هنا.
  • وضع الامتحان: عدّاد وقت والنتيجة في الآخر. وضع الدراسة: الإجابة الصحيحة تظهر بعد كل سؤال.
  • ⭐ Starred: علّم الأسئلة الصعبة وارجع لها في صفحة واحدة. 🔁 Mistakes: بيجمع كل أسئلتك الغلط ويشيل السؤال لما تجاوبه صح.
  • Export / Import backup: لنقل اختباراتك وعلاماتك ونتائجك بين الأجهزة والمتصفحات (الاستيراد بيدمج مع الموجود). اعمل Export قبل ما تضغط Clean all.
  • عند استيراد ملف تقدر تحدد من أي سؤال لأي سؤال تاخد (مثلاً أول 10 أو أول 20).

Prompt للذكاء الاصطناعي

I will give you exam questions (from a PDF, dump, or notes). Rewrite ALL of them in the exact format below. Output plain text only: no tables, no markdown symbols (no ** or #), no extra comments.

Rules:
1. Each question starts on a new line with: Question N: followed by the question text (N = running number: 1, 2, 3...).
2. Directly below it, write every option on its own line starting with A) B) C) D) (and E) F) if needed). One option per line.
3. After the options, write one line: Answer: X   (example: Answer: B). If several answers are correct, write: Answer: A, C
4. Leave one blank line between questions.
5. Do not skip, merge, shorten or reword any question. If the correct answer is not given, work it out carefully and still provide your best answer.

Example:
Question 1: Which protocol does a SOAP web service commonly use?
A) FTP
B) HTTP
C) SMTP only
D) None of these
Answer: B

Question 2: Which TWO are valid options?
A) Option one
B) Option two
C) Option three
D) Option four
Answer: A, C

Now convert the following questions:
