Quick guide

  • Your data stays in this browser. Question banks, starred questions, mistakes, and scores are saved locally on this device.
  • Import questions: add a PDF, Word (.docx), or TXT file. Review the extracted questions before saving the set; unusual document formatting may need manual correction.
  • Exam mode: answer questions and see your score at the end. Study mode: check answers as you go.
  • Starred: save difficult questions for revision. Mistakes: revisit questions you answered incorrectly.
  • Question ranges: when importing, choose a subset of the extracted questions if you do not want to import the whole file.
  • Backups: export a backup before moving to another browser or device. Importing a backup merges its data with the current library.
  • Clear all data permanently removes this app's saved question banks and progress from the current browser. Export a backup first if needed.
  • Import note: PDF and Word extraction use browser libraries loaded from a CDN and require an internet connection. TXT import works without those libraries.

Question formatting prompt

I will give you exam questions (from a PDF, dump, or notes). Rewrite ALL of them in the exact format below. Output plain text only: no tables, no markdown symbols (no ** or #), no extra comments.

Rules:
1. Each question starts on a new line with: Question N: followed by the question text (N = running number: 1, 2, 3...).
2. Directly below it, write every option on its own line starting with A) B) C) D) (and E) F) if needed). One option per line.
3. After the options, write one line: Answer: X   (example: Answer: B). If several answers are correct, write: Answer: A, C
4. Leave one blank line between questions.
5. Do not skip, merge, shorten or reword any question. If the correct answer is not given, work it out carefully and still provide your best answer.

Example:
Question 1: Which protocol does a SOAP web service commonly use?
A) FTP
B) HTTP
C) SMTP only
D) None of these
Answer: B

Question 2: Which TWO are valid options?
A) Option one
B) Option two
C) Option three
D) Option four
Answer: A, C
